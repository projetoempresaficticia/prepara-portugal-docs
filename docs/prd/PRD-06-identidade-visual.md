# PRD-06 — Identidade Visual por Empresa

> **Skills responsáveis:** `figma-ui-kits` · `figma-icons` · `prepara-deck-builder`
> **Estado:** parcial — falta o link do ficheiro Figma e a fonte de descrição das empresas.

---

## 1. Objetivo

Gerar um **brand kit por empresa fictícia**, reutilizando a biblioteca de ícones e o UI kit já existentes, recoloridos por perfil de empresa.

## 2. Escopo

- **Saída por empresa:** logótipo, tokens de cor, tipografia, subconjunto de ícones e guia de estilo.
- **`figma-ui-kits`:** escolhe o melhor UI kit / design system para construir cada app (alvo padrão: web responsivo).
- **`figma-icons`:** escolhe o kit de ícones e gera a biblioteca de SVGs otimizados.
- **`prepara-deck-builder`:** decks `.pptx` on-brand em inglês (onboarding, aulão inaugural, versões por curso, ebook → slides).

## 3. Bloqueios (a resolver antes de avançar)

- Falta o **link do ficheiro Figma** com a biblioteca de ícones/UI kit.
- Falta a **fonte de descrição das empresas** (para recolorir e escolher ícones por perfil).

## 4. Referências de marca existentes (no projeto)

- Brandbook Prepara Portugal (PDF/DOCX), Brandbook CFPP, briefing para criadores de conteúdo.
- Paleta já usada no Banco: `#8F41DE`, `#FF7535`, `#DAC0F4`, `#FFD6C2`, `#FFFFFF`, `#2C2C2C`.

## 5. Critério de aceitação

- Dada uma descrição de empresa, produzir logótipo + tokens + tipografia + subconjunto de ícones + guia de estilo coerentes com o perfil.
